Alcance inicial del proyecto

Desarrollar un sistema informático que permita administrar de manera organizada los productos las existencias, ventas de un negocio comercial,
Así mismo como actualizar inventario después de cada venta confirmada, consultar historial de ventas y generar factura sobre ventas de productos existentes a clientes

Requerimientos funcionales y no funcionales.

Funcionales.

Código					Requerimiento funcional	Prioridad
RF01					El sistema deberá permitir iniciar sesión mediante un nombre de usuario y una contraseña.	Bueno
RF02					El sistema deberá permitir registrar nuevos usuarios autorizados.	Alta
RF03					El sistema deberá permitir editar, consultar y desactivar usuarios.	Alta
RF04					El sistema deberá permitir asignar roles y permisos de acceso a los usuarios.	Alta
RF05					El sistema deberá permitir registrar nuevos productos.	Bueno


NO FUNCIONALES 

Código					Requerimiento no funcional							Categoría
RNF01					El sistema deberá contar con una interfaz intuitiva y fácil de utilizar.							Usabilidad
RNF02					El sistema deberá restringir el acceso a las funciones según el rol y los permisos del usuario.							Seguridad
RNF03					Las contraseñas deberán almacenarse mediante mecanismos seguros de hash, nunca como texto plano.							Seguridad
RNF04					El sistema deberá responder a las consultas habituales en un máximo de 3 segundos bajo condiciones normales de uso.							Rendimiento
RNF05					El sistema deberá validar los datos para evitar registros incompletos, duplicados o incorrectos.							Integridad
